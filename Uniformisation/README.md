# Instructions de lancement
---
**1 :** Créer un envrionnement virtuel Python <br>
`python -m venv venv`

**2 :** Activer l'envrionnement <br>
`source ./venv/bin/activate`

**3 :** Installer les dépendances <br>
`pip install -r requirements.txt`

**4 :** Lancer le programme <br>
`python brave_uniformisation.py ../utils/extension1.txt`
