# Instructions de lancement
---
**Etape 1 :** Créer un envrionnement virtuel Python
`python -m venv venv`

**Etape 2 :** Activer l'envrionnement
`source ./venv/bin/activate`

**Etape 3 :** Installer les dépendances
`pip install -r requirements.txt`

**Etape 4 :** Lancer le programme
`python plugins.py`
